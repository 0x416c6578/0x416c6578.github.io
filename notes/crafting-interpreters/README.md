## Crafting Interpreters
- Started reading / implementing on 24th February 2026
- Java implementation of the Lox programming language can be found at [github.com/0x416c6578/jlox](https://github.com/0x416c6578/jlox)

___

After learning the basics of programming language design by implementing a simple tree-walker interpreter for an SQL-like language at university, I wanted to pick up a book that goes into further detail on the topic. _Crafting Interpreters_ was recommended by my professor and other colleagues.
