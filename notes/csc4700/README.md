## CSC4700 Lectures - Parallel C++ for Scientific Applications
Hartmut Kaiser's lectures on C++ for scientific applications and HPC. I've enjoyed listening to ADSP the podcast for a while now so seeing this lecture series available online was a very welcome surprise.

I am not a C++ developer nor do I want to become one, however the C++ STL is regarded as one of the most beautiful and well engineered pieces of software ever written, so I hope I can learn at least a couple of things from this course
